# Python mini-shell — implementation directory

Start at the [repository README](../README.md) for verified commands, scope, examples, limitations, and regression-test instructions.

The implementation is [`app/main.py`](app/main.py), the original CodeCrafters-compatible launcher is [`your_program.sh`](your_program.sh), and regression tests are in [`tests/test_shell.py`](tests/test_shell.py). The project does not provide a `shell.py` file; run `python3 -m app.main` from **this directory**.
